# Privacy Policy for Harmes

Last updated: September 15, 2026

This Privacy Policy explains how **Harmes** ("Bot") collects, uses, and protects user data.

## 1. Data We Collect
Harmes may temporarily or permanently collect and process minimal data necessary for its functionality, including:
- **Discord User IDs**: To identify users, track permissions, and manage user preferences.
- **Discord Server (Guild) IDs**: To store server-specific settings and configurations.
- **Channel & Message IDs**: To execute commands or process interactions within designated channels.
- **Command Usage Logs**: To monitor performance, debug errors, and improve bot reliability.

*Harmes does not read, log, or store personal user messages outside of direct command interactions.*

## 2. How We Use Data
The collected data is strictly used to:
- Deliver core features and bot functionality.
- Save user and server configuration settings.
- Troubleshoot bugs and prevent abuse.

## 3. Data Sharing & Security
- We do not sell, rent, or share any collected data with third parties.
- All stored data is secured and accessible only by the Bot developer.

## 4. Data Retention & Deletion
- Data is retained only as long as necessary to provide service functionality.
- Server data is automatically removed or invalidated if the Bot is removed from the server.
- Users may request deletion of their stored data at any time by contacting the developer.

## 5. Contact
For privacy-related questions or data deletion requests, please reach out to the Bot developer on Discord.
